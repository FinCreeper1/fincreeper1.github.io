BrightShelf

Bildverwaltung für macOS

BrightShelf hilft dir, Bilder auf deinem Mac zu sortieren und zu verwalten. Die App arbeitet lokal und sammelt laut Projektbeschreibung keine personenbezogenen Daten; eine Netzwerkverbindung erfolgt bei einer ausdrücklich gestarteten Update-Prüfung.

Installation

Lade die neueste Version von GitHub herunter, entpacke die ZIP-Datei und ziehe BrightShelf in deinen Programme-Ordner.
